🎯 WHAT THIS ERROR MEANS:
═══════════════════════════════════════════════════════════════════

The frontend (React app) cannot connect to the backend (API server).

This means: THE BACKEND SERVER IS NOT RUNNING!


✅ INSTANT FIX (Run This):
═══════════════════════════════════════════════════════════════════

.\fix-failed-to-fetch.ps1

This script will:
  ✓ Check if backend is running
  ✓ Check if frontend is running
  ✓ Test the API connection
  ✓ Tell you exactly what to do


🔧 MANUAL FIX (3 Steps):
═══════════════════════════════════════════════════════════════════

STEP 1: Check if servers are running
   .\check-servers.ps1

STEP 2: If backend is NOT running, start it:
   Open PowerShell window #1:
   cd scripts/server
   npm start
   
   (Keep this window open!)

STEP 3: If frontend is NOT running, start it:
   Open PowerShell window #2:
   cd client
   npm start
   
   (Keep this window open!)


⚡ EASIEST FIX (Automated):
═══════════════════════════════════════════════════════════════════

.\start-clean.ps1

This will:
  ✓ Kill any old processes
  ✓ Start backend server
  ✓ Start frontend app
  ✓ Open both in new windows

═══════════════════════════════════════════════════════════════════
