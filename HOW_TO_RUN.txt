⚡ QUICK TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════

Problem: "Failed to fetch" error
Solution: .\fix-failed-to-fetch.ps1
          (This diagnoses and fixes the issue automatically)

Problem: Port already in use
Solution: .\start-clean.ps1
          (Kills old processes and starts fresh)

Problem: Cannot login
Solution: Make sure both servers are running
          Use: admin@test.com / admin123
          Check: .\check-servers.ps1

Problem: White screen
Solution: Wait 30-60 seconds for compilation
          Refresh browser (Ctrl+F5)
          Check both servers are running

For detailed help: See TROUBLESHOOTING.md
