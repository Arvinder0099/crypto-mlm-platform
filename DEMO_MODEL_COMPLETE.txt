🔧 HOW TO CUSTOMIZE
════════════════════════════════════════════════════════════════════════════

Change Default Balance:
 File: server/models/User.js
 Change: balance: { type: Number, default: 1000, min: 0 }
 To:     balance: { type: Number, default: 5000, min: 0 }

Add New Investment Plan:
 File: server/scripts/seed-demo-data.js
 Add to: demoPlans array
 Re-run: node seed-demo-data.js

Modify Commission Rates:
 File: server/models/AdminSettings.js
 Change: directCommissionRate: { type: Number, default: 10 }
 To:     directCommissionRate: { type: Number, default: 15 }

Change Withdrawal Fee:
 File: server/models/AdminSettings.js
 Change: withdrawalFeePercent: { type: Number, default: 2 }
 To:     withdrawalFeePercent: { type: Number, default: 5 }
